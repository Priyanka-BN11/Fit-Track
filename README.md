# Fitness Tracker

## Description
A full-stack web application that allows users to track their fitness activities, set goals, and monitor progress over time. The application features user profiles, activity logging, a progress dashboard, and social sharing capabilities.

## Key Features
- **User Profiles**: Create and manage profiles, including personal fitness goals.
- **Activity Logging**: Log workouts, track exercises, and input duration and calories burned.
- **Progress Dashboard**: Visual representation of user progress with interactive charts.
- **Social Sharing**: Share achievements with friends and follow each other’s progress.

## Technology Stack
### Frontend
- **React**: For building the user interface.
- **TypeScript**: To ensure type safety and improve code maintainability.
- **Chart.js**: For displaying progress and statistics visually.

### Backend
- **Node.js & Express**: To create a RESTful API for user and activity management.
- **MongoDB**: For storing user data and fitness activity records.

## Getting Started

### Prerequisites
- Node.js and npm installed on your machine.
- MongoDB installed or use a cloud service like MongoDB Atlas.
